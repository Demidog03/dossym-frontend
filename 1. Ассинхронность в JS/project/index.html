Живой поиск

Поле ищет по справочнику JavaScript, пока вы печатаете. Ваша задача — сделать так, чтобы запрос уходил на сервер не на каждую букву, а один раз, когда человек закончил печатать. Панель справа показывает, сколько запросов создаёт ваш код.

    0 нажатий клавиш
    0 запросов к серверу
    — запросов сэкономлено

    Журнал сети

    1. Начните печатать в поле поиска.
    Задание

    Шаг 1 — посмотрите, как есть сейчас. Откройте script.js: наивная версия уже написана. Наберите в поле слово из шести букв и посмотрите на счётчики. Шесть букв — шесть запросов. Реальный сервер такого не любит.

    Шаг 2 — сделайте задержку (это главное). Пусть запрос уходит только тогда, когда человек не печатал 400 мс. Каждое новое нажатие отменяет запланированный запрос через clearTimeout и планирует новый через setTimeout. Цель: набрать шесть букв подряд и увидеть один запрос.

    Шаг 3 — бонусы, если успели. Не отправлять запрос короче двух символов; показывать «Ищу…» во время ожидания ответа; не показывать устаревший ответ, если пока он летел, текст в поле успел измениться.

    Файл lab.js трогать не нужно — там имитация сервера и приборная панель. Всё, что вам нужно, описано в комментариях к script.js.
